# Beispielprojekt „Muster Maschinenbau GmbH“

Fiktiver Sondermaschinenbauer (600 MA), vollständig durchgespielt: alle Methoden-Tools sind befüllt und ausgewertet.

- `demo-maschinenbau/01_Workshop-Input/Workshop-Erfassung.xlsx`: ausgefüllte Erfassung, ein Blatt je Methode
- `demo-maschinenbau/02_Ergebnisse/Beispiel_Digitalisierungsstrategie.pptx`: generiertes Strategiedeck
- `demo-maschinenbau/02_Ergebnisse/Beispiel_Auswertung.xlsx`: Excel-Auswertung mit Formeln
- `demo-maschinenbau/02_Ergebnisse/BPMN/`: Ist-Prozess als BPMN 2.0
- `demo-maschinenbau/00_Workshopplanung/`: Workshop-Serie, Agenden, Leitfäden, Erfassungsvorlagen

Die Daten sind bewusst nicht ganz fehlerfrei, damit die Prüfungen sichtbar werden: eine RACI-Zeile hat zwei „A“,
und einige User Stories verletzen INVEST.

Neu erzeugen:

```bash
digistrat demo examples/demo-maschinenbau
```
